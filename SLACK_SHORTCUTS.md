# Slack Keyboard Shortcuts (macOS)

Navigate Slack entirely from the keyboard. Organized by workflow.

---

## Quick Navigation

| Shortcut              | Action                              |
| --------------------- | ----------------------------------- |
| `⌘+K`                | **Quick Switcher** — jump to any channel, DM, or person by typing a name |
| `⌘+T`                | Same as ⌘+K (alternative)           |
| `⌘+G`                | Search within current conversation  |
| `⌘+F`                | **Search** all of Slack              |
| `⌘+Shift+K`          | Open DMs browser                    |
| `⌘+Shift+L`          | Browse channels                     |
| `⌘+Shift+T`          | Open Threads view                   |

> **Pro tip:** `⌘+K` is the single most important shortcut. You should almost
> never use the mouse to switch channels. Just hit `⌘+K`, type a few letters
> of the channel or person name, Enter.

## Workflow: "Process All Unreads in 60 Seconds"

1. `⌘+Shift+A` — open All Unreads view
2. Read each unread section
3. `Escape` — mark current channel read, moves to next
4. If you need to respond: `T` to open thread, type reply, `⌘+Shift+Enter`
5. `Escape` to close thread, continue
6. When done, `Shift+Escape` — mark everything remaining as read

---

## Workflow: "Jump Into a Specific Conversation"

1. `⌘+K` — open Quick Switcher
2. Type first 2-3 letters of person or channel name
3. `Enter` — jump there
4. Read/respond
5. `⌘+[` — go back to where you were

---

## Workflow: "Find Something Someone Said"

1. `⌘+F` — open search
2. Type query (use `from:@person` to filter by sender, `in:#channel` to
   filter by channel, `before:2026-01-01` or `after:2026-01-01` for dates)
3. `Enter` — search
4. Arrow keys to navigate results
5. `Enter` — jump to message in context
6. `⌘+[` — go back to search results

---

## Tips for Mouse-Free Slack

- **`⌘+K` is your home base.** Train yourself to use it instead of scrolling
  the sidebar. It's faster even for channels you can see.
- **`F6` cycles focus areas.** If keyboard shortcuts aren't working, you're
  probably focused on the wrong area. Hit `F6` until you're in the right spot.
- **`⌥+Shift+↑/↓` for unread hopping** is the fastest way to catch up on
  multiple channels without touching the mouse.
- **`Escape` = "I'm done here."** It marks as read and lets you move on.
- **`R` then type emoji name** for quick reactions without reaching for the
  mouse. e.g. `R` then type `eyes` then `Enter` for 👀.
